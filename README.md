# Real-Time Gesture-Controlled Interactive Object

A computer vision application developed in **Python** that enables real-time, gesture-controlled object manipulation using a webcam interface. This project utilizes **MediaPipe** for hand tracking, **OpenCV** for video capture, and **Pygame** for interactive rendering.

## Key Features
* **Fingertip Tracking:** Leverages 3D hand landmark detection to track index fingertip coordinates in real-time.
* **Dynamic Rendering:** Features a Pygame-rendered object that responds fluidly to the user's hand movements.
* **Computer Vision Integration:** Incorporates OpenCV for optimized frame capture and image processing.

## Technologies Used
* **Python** (Core Logic)
* **OpenCV** (Video Capture & Processing)
* **MediaPipe** (Hand Tracking & Landmarks)
* **Pygame** (GUI & Graphical Rendering)
